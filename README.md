## 🚀 Como Rodar Localmente

Por ser um projeto estático (sem build steps), basta abrir o `index.html` diretamente no navegador ou usar qualquer servidor local:

```bash
# Com Python 3
python3 -m http.server 8080

# Com Node.js (npx)
npx serve .
```

Depois acesse: `http://localhost:8080`
